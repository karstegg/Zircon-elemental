# Zircon Elemental: project context for Claude Code

Open-source revival of **SynC Modular** (Dr SynC / Vadim Zavalishin, 1999–2003, freeware, no source).
It is a clean-room rebuild: we never use original code, and the `.sm` format is only to be reverse-engineered for import.
Goal: build *any* audio software from math primitives, with premade macros/modules on top.
Ships as a VST3 plugin with a modern UI; an AI patch designer comes later.

Owner: Greg (electrical engineer). He prefers concise, direct execution and targeted questions.

## Decisions already made
- **Name**: Zircon Elemental. "Elemental" = the primitive math layer.
- **Platforms**: Windows x64 is the official target (CI in `.github/workflows/build.yml`). macOS/Linux are left to community forks; keep code portable.
- **Licence**: AGPL-3.0 (forced by the JUCE 8 free tier). The core has no JUCE dependency, so the wrapper could later move to iPlug2/DPF.
- **Patch format**: JSON, git-diffable (see README). Macros nest; feedback loops need `z1`/`delay`.
- **Patch library**: bundle only official/user ensembles whose authors cleared them. Sources: the KVR shared Drive folder (authorised-only) and mvxsynths.blogspot archive.

## What sets it apart from Reaktor (keep these true)
1. One layer from math primitive to instrument (no Primary/Core split)
2. Export a patch as a standalone VST3/CLAP (planned)
3. AI designer: describe a sound → proposed patch → audition → refine (planned)
4. Text/JSON patches; 5. open source, cross-platform

Old SynC user complaints to address: steep curve/"DSP black art", thin docs, few presets, dated GUI,
missing audio-in/multi-out/MIDI clock, host automation quirks.

## Layout
- `core/` engine (C++20): `ops` catalogue → `compiler` (flatten macros, topo-sort, z1 breaks loops, summed inputs) → `engine` (per-sample, loops over 16 voice lanes)
- `library/macros/` primitive-built macros (Phasor, Saw, SineOsc, OnePoleLP ZDF, RamanMode, ZirconLattice, AlphaStrike)
- `patches/` 01–05 demos, 06–08 Zircon Lattice presets (generated by `tools/gen_zircon.py`; edit the generator, not the JSON)
- `cli/` `zircon render|info|modules`; `tests/` 12 tests; `plugin/` JUCE VST3 + Standalone (factory patches = host programs, auto knob panel, 16 host param slots)
- `docs/ZIRCON.md` crystal-physics voice (Raman modes, metamict, birefringence, dispersion, alpha decay)

## Build (Windows)
```
cmake -S . -B build -DZIRCON_BUILD_PLUGIN=ON        # fetches JUCE 8.0.4
cmake --build build --config Release
ctest --test-dir build -C Release
```
The VST3 lands in `build/plugin/ZirconElemental_artefacts/Release/VST3/`. Copy it to `C:\Program Files\Common Files\VST3`.
